# 🌕 MOONCOURT — The Werewolf Society (Multi-Device Server)

ชุดโค้ดฝั่งเซิร์ฟเวอร์ (Node.js + Express + Socket.IO) และหน้าเว็บพร้อม Deploy สำหรับเล่นเกม Werewolf แบบล้อมวงด้วยมือถือคนละเครื่อง ไม่ต้องล็อกอิน ใช้เพียงรหัสห้อง 6 หลัก โดยมีระบบ **Auto-Moderator** คุมเกมเบื้องหลังให้ Host ร่วมเล่นได้จริง 100%

---

## ✨ ความสามารถของระบบฝั่งเซิร์ฟเวอร์
- **Authoritative Server (กันโกง 100%):** บทบาทลับของทุกคนถูกเก็บไว้เฉพาะบนเซิร์ฟเวอร์และส่งเฉพาะข้อมูลของเครื่องนั้นๆ (Host ไม่เห็นบทบาทเพื่อน) และปิดบังบทบาทผู้เสียชีวิตทุกคนจนกว่าเกมจะจบ
- **Auto-Reconnect (รีเฟรชหน้าจอไม่หลุด):** ใช้ `sessionToken` แบบไม่ต้องล็อกอิน หากมือถือล็อกหน้าจอหรือรีเฟรชเบราว์เซอร์ ระบบจะดึงกลับเข้าห้องและบทบาทเดิมให้อัตโนมัติ
- **12 Secret Identities:** Werewolf, Wolf Cub, Defender, Seer, Witch, Hunter, Cupid, Spellcaster, Revealer, Huntress, Villager และ Tanner (ฝ่ายอิสระ)
- **6 เฟส + การ์ดเหตุการณ์รายคืน:** เปิดดูบทบาท → กลางคืน (พร้อมปุ่ม Decoy Tap) → รุ่งเช้า (แอนิเมชันหมอกสรุปทีละสเต็ป) → พูดคุยกลางวัน → โหวตเสนอชื่อ → แก้ต่าง/ตัดสิน → Second Chance
- **โหมดจอกลางวง (TV / iPad Display):** เข้าผ่านปุ่ม TV หรือ URL `/?tv=รหัสห้อง6หลัก` เพื่อแสดงตัวจับเวลา แอนิเมชันรุ่งเช้า และผลโหวตกลางวงโดยไม่เปิดเผยความลับใคร

## 🚀 วิธีที่ 1: รันเล่นบน Wi-Fi เดียวกันทันที (Local LAN)
เหมาะสำหรับเปิดบนโน้ตบุ๊กแล้วให้เพื่อนในวงเชื่อมต่อผ่าน Wi-Fi เดียวกัน (ฟรี 100% และเร็วมาก):

1. ติดตั้ง [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป)
2. แตกไฟล์ `mooncourt-server.zip` แล้วเปิด Terminal เข้าไปในโฟลเดอร์ `mooncourt-server`
3. รันคำสั่ง:
   ```bash
   npm install
   npm start
   ```
4. เซิร์ฟเวอร์จะแสดงลิงก์ Local Wi-Fi (เช่น `http://192.168.1.42:3000`) — ให้เพื่อนทุกคนในวงเปิดลิงก์นั้นบนมือถือ หรือสแกน QR Code จากหน้าห้องได้เลย!

## 🌐 วิธีที่ 2: Deploy ขึ้นเว็บฟรีเพื่อรับลิงก์ `https://...` (Render.com)
เหมาะสำหรับเล่นผ่าน 4G/5G โดยไม่ต้องอยู่ Wi-Fi เดียวกัน:

1. อัปโหลดโฟลเดอร์ `mooncourt-server` ขึ้น GitHub Repository ของคุณ
2. ไปที่ [Render.com](https://render.com) → กด **New +** → เลือก **Blueprint** (หรือ **Web Service**) แล้วเชื่อมต่อกับ GitHub Repo นี้
3. Render จะอ่านไฟล์ `render.yaml` อัตโนมัติ (Build: `npm install`, Start: `npm start`)
4. รอประมาณ 2 นาที คุณจะได้ลิงก์สาธารณะ เช่น `https://mooncourt-werewolf.onrender.com` ส่งให้เพื่อนเข้าเล่นบนมือถือได้ทันที!

> 💡 **หมายเหตุสำหรับ Free Tier:** หากไม่มีคนเข้าใช้งานเกิน 15 นาที Render Free Tier จะพักเครื่องชั่วคราว (Cold Start ~30 วินาทีตอนเปิดครั้งแรก) หลังจากนั้นจะลื่นตลอดทั้งวงครับ
